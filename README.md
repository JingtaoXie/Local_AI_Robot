A locally deployed AI model–powered agent capable of basic voice interaction. The system leverages a Retrieval-Augmented Generation (RAG) architecture, enabling users to upload custom PDF documents to build a domain-specific knowledge base, thereby enhancing the model’s contextual understanding and response accuracy.

该项目基于本地部署的AI模型构建，实现了基础的语音交互功能。系统采用检索增强生成（RAG）架构，支持用户通过上传PDF文档来构建专属知识库，从而有效提升模型的上下文理解能力与问答准确性。
